# 02. 시스템

## 0. 성장 3축

| 축 | 역할 | 포맷(환생) 시 | 주는 재미 |
|---|---|---|---|
| 하드웨어 | 기초 체력 (파워) | 1레벨로 초기화 | 숫자가 폭증하는 인플레이션 쾌감 |
| 해킹 툴 | 빌드 (전략) | 장착만 해제, 툴은 영구 소장 | 상황에 맞춰 갈아 끼우는 전략성 |
| 악명 | 메타 진행 (위상) | 영구 누적 | 남에게 보여지는 명예, 다음 회차 편의 |

레벨 · 업적은 이 3축 사이에서 **단기 목표**를 계속 던져 주는 역할이다.

## 1. 재화

| 재화 | 얻는 곳 | 쓰는 곳 | 포맷 시 |
|---|---|---|---|
| 크레딧 | 자동 해킹, 수동 클릭, 오프라인 보상, 메가코프 최초 돌파, 일일 던전, 업적 일부 | 하드웨어, 상점 툴, 크루 생성 · 기부 | 0으로 초기화 |
| 다이아 | 업적 (대부분 GEM 보상) | CPS 부스트 (§5.3) | 유지 |
| 악명 포인트 | 포맷 | 악명 스킬 | 유지 |
| 경험치 | 크레딧 100당 1 | 레벨 | 포맷 시작 레벨로 |

**크레딧 표기**: 1,000 미만 그대로 · K (15.5K) · M (3.2M) · B (1.8B). HUD에는 크레딧 · CPS · 오프라인 시간을 항상 표시하고, 숫자는 카운트업 애니메이션으로 올린다.

## 2. 하드웨어

| 부품 | 표시 이름 (Lv1 → Lv100) | 방치 수입(CPS)에서 | 보스 피해(DPS)에서 |
|---|---|---|---|
| CPU | 8-bit Chip → Nirvana | 기본 수입 `11 × Lv` | 기본 피해 `120 × Lv` |
| RAM | 64KB Memory → Omniscience | 해킹 라인 `1 + Lv / 2` (곱) | 배율 `1 + 0.1 × Lv` |
| Network | 56k Modem → Nirvana Link | 속도 `1 + 0.15 × Lv` (곱) | 배율 `1 + 0.05 × Lv` |

- 레벨 1 ~ **100** (최대)
- 비용: `기본가 × 1.3 ^ 현재레벨` · 기본가 CPU 10,000 / RAM 30,000 / Network 20,000
- 세 부품이 **곱으로** 묶여 있어, 한 부품만 올리는 것보다 고르게 올리는 쪽이 효율이 좋다
- **부품마다 계수와 비용을 다르게 둔 이유**: 하드웨어마다 주는 느낌이 달라야 한다. 셋 다 같은 타이밍에 같은 돈으로 올리면 고르는 재미가 없어서, 실제 장비 가격을 참고해 비용(RAM ×3 · NET ×2)과 CPS · DPS 계수를 다르게 넣었다
- [계획] 레벨 구간마다 책상 위 장비의 LED가 바뀐다: 1 ~ 25 녹색 정적 · 26 ~ 50 청록 점멸 · 51 ~ 75 주황 데이터 스트림 · 76+ 보라/백색 맥동

## 3. 해킹 툴

### 3.1 개요

- 단순 스펙업이 아니라 **하드웨어 효율을 늘리는 장착형 모듈**
- 한 번 얻으면 영구 소장. 포맷하면 장착만 풀린다
- 100종 · 효과 5가지 × 등급 4가지

| 효과 | 내용 | 개수 |
|---|---|---|
| HW_CPU_EFFICIENCY | CPU 효율 +% | 20 |
| HW_RAM_EFFICIENCY | RAM 효율 +% | 20 |
| HW_NET_EFFICIENCY | Network 효율 +% | 20 |
| CREDIT_BONUS | 크레딧 획득량 +% | 20 |
| CLICK_DMG_PER | 수동 클릭 효율 +% | 20 |

| 등급 | 개수 | 효과 범위 | 상점 가격 |
|---|---|---|---|
| 일반 | 40 | +3 ~ 5% | 해금 티어 예상 CPS 1시간치 |
| 희귀 | 30 | +6 ~ 10% | 3시간치 |
| 영웅 | 20 | +12 ~ 18% | 8시간치 |
| 전설 | 10 | +25 ~ 35% | 드랍 전용 |

### 3.2 장착 슬롯

| 플레이어 레벨 | 1 | 10 | 25 | 50 | 100 |
|---|---|---|---|---|---|
| 슬롯 | 3 | 4 | 5 | 6 | 7 |

의도: 포맷 직후에는 좋은 툴이 있어도 슬롯이 모자라 다 못 쓴다 → 레벨을 다시 빨리 올릴 이유가 생긴다.

### 3.3 획득

| 경로 | 비율 | 비고 |
|---|---|---|
| 상점 구매 | 66종 | 일반 · 희귀 · 영웅. 전설은 팔지 않는다 |
| 드랍 | 34종 | 일일 툴 던전 (콘텐츠 §2) |

### 3.4 효율 상한

- 같은 하드웨어의 툴 효율 합은 **+100%까지** (CPU · RAM · Network 각각)
- 크레딧 획득량 보너스 합은 **+300%까지**
- 상한에 닿으면 서버가 밸런스 로그를 남긴다 (§8)

[계획] 세트 효과 (예: Ghost Protocol + Stealth Protocol → CPS +10%). 코드에는 시너지 배율 · 슬롯 추가 · 보스 시간 연장 · 보스 HP 감소 효과 자리가 있지만, 현재 데이터에서 쓰는 툴은 없다.

## 4. 전투 (메가코프)

### 4.1 진행

```
보스 도전 → 제한 시간 20초 시작
  매초: 보스 HP -= 내 DPS
  클릭: 보스 HP -= 내 DPS × 5%
  → HP 0: 성공 → 다음 레이어 (최초 돌파면 보상 · 점령 수입 교체)
  → 시간 초과: 실패 → 파밍 모드 (이전 단계에서 수입 쌓기)
```

### 4.2 DPS와 위협도

```
DPS = (120 × CPU) × (1 + 0.1 × RAM) × (1 + 0.05 × NET)   ← 각 항에 악명 스킬 · 툴 효율 반영
    × (1 + 전체 피해%)
    × (1 + 섹터 피해%)        ← 보스 섹터와 맞는 툴
    × (1 + 보스 피해%)        ← 보스 레이어에서만
    × 레벨 계수 1.04 ^ (레벨 - 1)
    × 악명 배율 (§8.3)
```

- **위협도**: 같은 공식에서 섹터 · 보스 보너스를 뺀 값. 화면 상단과 프로필 「스캔」 연출에 보여 주는 **대표 전투력**
- 일일 던전 난이도의 입장 조건으로도 쓴다

### 4.3 CPS와 DPS를 나눈 이유

- **CPS(돈)** 와 **DPS(힘)** 는 같은 하드웨어로 오르지만 계수가 다르다 (부품마다 주는 느낌을 다르게, §2)
- 레벨 · 악명은 DPS에만 곱해진다 → 포맷하면 수입은 처음부터지만 보스는 더 빨리 깬다 → 다음 회차가 빨라지는 체감

## 5. 수입

### 5.1 자동 해킹

- 서버가 **5초마다** `CPS × 5` 크레딧을 지급하고, 이번 틱 증가분만 클라이언트에 보낸다
- 접속 중이 아닐 때 쌓인 수입은 다음 요청 때 한꺼번에 정산 (최대 24시간)

### 5.2 수동 클릭 (크레딧)

- 클릭 1회 = **CPS × 1** 크레딧
- 클라이언트가 5초마다 클릭 수를 모아 보낸다 · **5초에 150회 (초당 30회) 초과는 무효**

### 5.3 CPS 부스트 (다이아)

| 시간 | 다이아 | 보너스 |
|---|---|---|
| 1시간 | 10 | 0% |
| 3시간 | 28 | +5% |
| 6시간 | 50 | +10% |
| 12시간 | 90 | +15% |
| 24시간 | 160 | +20% |
| 48시간 | 280 | +25% |
| 72시간 | 380 | +30% |

현재 CPS로 N시간치 크레딧을 즉시 받는다. 길게 살수록 할인 (1시간당 10 → 5.3 다이아).

## 6. 오프라인 보상

```
오프라인 크레딧 = CPS × 오프라인 시간(초) × 효율
효율 = 0.8 (오프라인 위주 방향) + 오프라인 효율 툴 (최대 1.0 · 현재 데이터에는 해당 툴 없음)
오프라인 시간: 10초 미만은 무시 · 최대 12시간
```

- 로그아웃 시각과 접속 시각을 **서버 시간**으로 잰다 → 기기 시간을 바꿔도 보상이 늘지 않는다

## 7. 레벨과 경험치

- 크레딧 **100당 경험치 1** (어디서 얻은 크레딧이든)
- 필요 경험치: `데이터 재설계/NP_밸런스_데이터.xlsx` 05_경험치 (1회차 끝 약 72시간에 Lv60)
- 레벨업 효과: DPS 레벨 계수 ×1.04, 툴 슬롯 해금 (§3.2), 크루 생성 가능 (Lv10)
- 레벨업 보상: 그 레벨 예상 CPS **3분치**

## 8. 포맷 (신분 세탁) 과 악명

### 8.1 조건과 연출

- 조건: **레벨 60 이상** + 메가코프 첫 스테이지 클리어
- 연출: `C:\> FORMAT C: /S /Q`

### 8.2 초기화 / 유지

| 초기화 | 유지 |
|---|---|
| 크레딧 → 0 | 해킹 툴 (장착만 해제) |
| 하드웨어 → 1레벨 | 다이아 |
| 레벨 → 1 (+시작 레벨 스킬), 경험치 → 0 | 악명 레벨 · 포인트 · 스킬 |
| 메가코프 진행 → 7001, 점령 수입 → 0 | 업적 |

### 8.3 악명

- 포맷할 때마다 **악명 레벨 +1**, 레벨 k에서 DPS에 `1.25 + 0.3 × (k - 1)`을 곱한다 (×1.25 → ×1.55 → ×1.85 …, 10회차 누적 ×1,936)
- 곱하는 값이 회차마다 커져서, 이전 최고 지점까지 돌아오는 시간이 48 → 36 → 24 → 12시간으로 줄어든다
- 획득 포인트 = `1 + (최고 클리어 스테이지 - 7001) / 25` → 끝까지 깨면 20포인트
- 표기: 채팅 · 랭킹에 로마 숫자 (`[V] User`)

### 8.4 악명 스킬

10종 × 10단계 = 100개. 단계별 비용 1 · 1 · 2 · 2 · 3 · 3 · 4 · 5 · 6 · 7 (한 종 34, 전체 340 → 포맷 약 15번이면 전부).

| 종류 | 단계당 효과 |
|---|---|
| CPU / RAM / NET 증폭 (+) | 하드웨어 **레벨 +1** (계수가 다른 CPS · DPS에 같은 의미로) |
| CPU / RAM / NET 효율 (×) | +3% |
| 크레딧 마이닝 | 크레딧 획득량 +4% |
| 흥정 | 상점 비용 1% 할인 |
| 백도어 | 보스 대상 피해 +3% |
| 신분위조 | 포맷 후 시작 레벨 +3 |

의도: 툴이 "강해지는 것"이라면 악명 스킬은 **다음 회차를 편하게** 만드는 것 (시작 레벨, 할인).

## 9. 서버 검증 (치트 · 동기화)

| 항목 | 방식 |
|---|---|
| 클릭 매크로 | 5초 배치 단위로 받아 150회 초과면 거절 · 의심 로그 |
| 보스 피해 조작 | 클라이언트가 보낸 총 피해가 `DPS × (경과시간 + 1) × 1.2`를 넘으면 거절 |
| 오프라인 시간 조작 | 서버 시각 기준, 12시간 상한 |
| 수입 중복 지급 | 오프라인 보상을 주면 정산 시각을 현재로 초기화 |
| 패킷 롤백 | 크레딧은 절댓값이 아니라 **증가분**만 보낸다 |
| 밸런스 모니터링 | 효율 상한 · 소프트캡 도달 시 `balance_warning_log` 기록, 레벨별 평균 CPS 집계 (`analyze_balance.sh`) |
