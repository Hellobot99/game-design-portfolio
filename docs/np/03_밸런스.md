# 03. 밸런스

> 수치 v3. 기존 데이터의 문제(04_수정_기록 §2)를 고치려고 공식과 수치를 처음부터 다시 설계했다.
> 데이터: `데이터 재설계/NP_밸런스_데이터.xlsx` · 시뮬레이터: `데이터 재설계/sim/` · 과정: `데이터 재설계/00_진행노트.md`

## 0. 설계 원칙

1. **목표 플레이 시간에서 거꾸로 정한다**: 숫자부터 정하지 않고, "몇 시간에 어디까지"를 먼저 정한 뒤 공식과 표를 맞춘다.
2. **곱으로 키우고, 곱에는 뚜껑을 씌운다**: 하드웨어 · 툴 · 레벨 · 악명이 서로 곱해진다. 툴 효율 +100%, 크레딧 보너스 +300%, 전체 배율 10배 이후 로그 증가.
3. **돈(CPS)과 힘(DPS)을 분리한다**: 레벨 · 악명은 DPS에만 곱해져, 포맷 뒤 돈은 처음부터지만 보스는 빨리 깬다.
4. **비용 · 보상은 "CPS 몇 분치"로 정한다**: CPS가 바뀌어도 체감이 유지되고, 7.2경 같은 숫자가 생기지 않는다.
5. **오프라인 위주**: 하루 2번 × 20분 접속이 기준이라 방치 수입이 주가 된다.

## 1. 기준값

| 기준 | 값 |
|---|---|
| 하루 패턴 | 2번 × 20분 접속 (12시간 간격) |
| 1회차 | 80시간 안에 30티어 · Lv60 → 첫 포맷 |
| 2회차부터 | 회차 길이 약 71시간 = 이전 최고 지점 복귀 + 신규 진행. 복귀 시간은 회차마다 짧아짐 |
| 엔드게임 | 30일 · 포맷 10번 · 100티어 |
| 수입 | 오프라인 위주 (효율 80%) |

## 2. 공식

### 2.1 CPS (평소 해킹 → 크레딧)

```
CPS = 11·CPU × (1 + RAM/2) × (1 + 0.15·NET)        ← 각 항에 툴 효율(부품별 최대 +100%) · 악명 스킬
    × (1 + 크레딧 보너스(최대 +300%) + 스킬 크레딧%)
    × (1 + 0.005 × 점령 티어) × (1 + 크루)
전체 배율 10배 이후: 배율 = 10 + log10(배율 - 9)
오프라인: CPS × 시간 × 0.8, 최대 12시간
```

### 2.2 DPS (보스전 → 보스 HP)

```
DPS = 120·CPU × (1 + 0.1·RAM) × (1 + 0.05·NET)      ← 각 항에 툴 효율 · 악명 스킬
    × 1.04 ^ (레벨 - 1)
    × 악명 배율 = Π (1.25 + 0.3 × (k - 1)),  k = 1 … 악명 레벨
    × (1 + 전체 피해%) × (1 + 섹터 피해%) × (1 + 보스 피해%)
클릭 1회 = DPS × 5%
```

부품마다 계수 · 비용이 다른 이유: 하드웨어마다 주는 느낌이 달라야 해서. 같은 타이밍 · 같은 돈으로 셋 다 올리면 고르는 재미가 없다 (실제 장비 가격 참고).

### 2.3 그 밖

| 항목 | 공식 / 값 |
|---|---|
| 하드웨어 비용 | `기본가 × 1.3 ^ 현재레벨` · CPU 10,000 · RAM 30,000 · NET 20,000 |
| 경험치 | 크레딧 100 = 1 · 표는 1회차 시뮬레이션의 누적 수입에 맞춤 (Lv60 ≈ 72시간) |
| 보스 HP | `목표 DPS(티어) × 20초 × 레이어 계수` (0.3 / 0.45 / 0.6 / 0.8 / 1.0) |
| 목표 DPS | 1 ~ 30티어: 1회차 세션별 DPS / 31티어부터: 티어마다 `× 1.05 × 1.0023^(티어-31)` |
| 보상 | 레이어 돌파 CPS 20초 · 보스 2분 · 레벨업 3분 · 일일 던전 30 / 45 / 60 / 90분치 |
| 점령 수입 | 기본 CPS × 0.5% × 점령 티어 (교체 방식) |
| 툴 가격 | 해금 티어 예상 CPS × 1 / 3 / 8시간 (일반 / 희귀 / 영웅) |
| 악명 포인트 | `1 + (최고 클리어 ID - 7001) / 25` → 1회차 약 7, 10회차 약 20 |
| 악명 스킬 | 단계 비용 1 · 1 · 2 · 2 · 3 · 3 · 4 · 5 · 6 · 7 (전체 340) |

## 3. 성장 분할 (DPS가 어디서 나오는지)

1회차 끝(Lv1 · 하드웨어 1 대비)의 DPS 배율을 축별로 나누면 (로그 기준 기여도):

| 시점 | 하드웨어 | 레벨 | 악명 | 툴 · 스킬 |
|---|---|---|---|---|
| 1회차 끝 (29티어) | **74%** (×527) | 26% (×9.4) | 0% | 0% |
| 5회차 끝 (63티어) | 57% (×690) | 23% (×13.8) | 18% (×7.7) | 2% |
| 10회차 끝 (100티어) | 38% (×828) | 17% (×18.9) | **43%** (×1,936) | 3% |

- 한 회차 안의 성장은 **하드웨어**가, 회차를 넘는 성장은 **악명**이 맡는다 → 성장 3축 의도(하드웨어 = 쾌감, 악명 = 장기)와 같다
- 툴의 CPS 효과는 하드웨어를 더 높이 올리는 것으로 나타나서 "하드웨어" 쪽에 포함된다 (1회차 끝 CPU 43 → 10회차 끝 51)
