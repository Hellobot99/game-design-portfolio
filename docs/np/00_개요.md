## 1. 한 줄 소개

고독한 해커가 Lofi 음악이 흐르는 작업실에서 거대 기업(메가코프)의 서버를 하나씩 뚫어 가는 방치형 게임. 긴박한 전투보다 틀어 두고 일하거나 공부하는 "작업용 플레이리스트" 같은 무드를 지향한다.

## 2. 핵심 루프

```
해킹 (자동 + 수동 클릭)
  → 크레딧 · 경험치 획득
  → 하드웨어 업그레이드 · 해킹 툴 장착
  → 메가코프 보스 돌파 (점령 수입 증가)
  → 포맷(환생)으로 악명 획득 → 악명 스킬로 다음 회차 가속
```

| 주기 | 플레이어가 하는 일 | 관련 문서 |
|---|---|---|
| 초 단위 | 화면 클릭으로 크레딧 · 보스 피해 추가 | 시스템 §4 |
| 분 단위 | 하드웨어 업그레이드, 툴 교체 | 시스템 §2 · §3 |
| 시간 단위 | 메가코프 레이어 돌파, 월드 이벤트 대응 | 콘텐츠 §1 · §3 |
| 하루 단위 | 일일 던전 3회, 오프라인 보상 수령 | 콘텐츠 §2 · 시스템 §5 |
| 장기 | 포맷 · 악명 스킬, 업적, 크루 | 시스템 §6 · 콘텐츠 §4 · §5 |

## 4. 수치의 기준

- 구조(시스템 · 콘텐츠)는 실제 서버 코드 기준으로 정리했고, **공식과 수치는 v3로 다시 설계**했다 (`데이터 재설계/`).
- 구현되지 않은 기획은 지우지 않고 **[계획]** 으로 표시했다.
- 데이터 자체에 문제가 있는 값은 그대로 옮기지 않고 [04_수정_기록](04_수정_기록.md) §2 에 모았다.
